QURBANDONG ODOT - APLIKASI HP (PWA) USAHA TANI RUMPUT ODOT
==========================================================
Alamat aplikasi : https://ululalbabp-hub.github.io/qurbandong-app/odot/
Server          : Apps Script yang menempel di spreadsheet "Rumput Odot QDF 2026-2028" (Code.gs, doPost).
Alamat server   : config.js (apiUrl). Bisa juga diatur sekali lewat .../odot/?api=ALAMAT_EXEC

Folder ini terpisah dari aplikasi QDF Ternak di folder induk: ikon, nama, dan cache berbeda,
sehingga keduanya bisa dipasang berdampingan di layar utama HP.
